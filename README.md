# Sales Performance Analysis

## Project Overview
Analyzed retail sales data using Tableau to identify monthly sales trends, product category performance, and regional profitability.

## Tools & Technologies
- Tableau Desktop

## Dashboard Features
- Key performance indicators (KPIs) for total sales, total profit, and total quantity sold.
- Monthly sales trend analysis.
- Sales performance by product category.
- Profitability comparison across regions.
- Interactive filters for year, category, and region.

## Key Findings
- Technology was the highest-sales category in most regions, while Furniture led in the West.
- Identified differences in sales and profitability across regions and product categories.
- Used interactive filters to explore how sales performance changed across years, categories, and regions.

- Dashboard development
- Tableau calculations and interactive filters
